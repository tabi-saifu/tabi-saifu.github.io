# 見た目の確認項目

自動テストは「動き」（計算・操作の流れ・データの見え方）だけを確かめます。見た目は、画面を変えたときにこの表で確認します。

## 確認する条件

- 幅: **375px**（多くのiPhone）と **320px**（いちばん狭い機種）
- 色: **ライト**と**ダーク**（端末の設定がダークモードの人向け）
- 入力欄は**空のとき**と**入力したとき**の両方
- 可能なら実機の **iPhone（Safari）** と **Android（Chrome）**。パソコンの再現では、iPhone の日付・選択欄などの表示は再現できません

## 全画面に共通

| # | 確認すること |
| --- | --- |
| C1 | 画面が左右に動かない（横スクロールが出ない）。シートを開いたときも同じ |
| C2 | ボタン・タブ・チップの文字が枠からはみ出さない。折り返す場合も読みやすい |
| C3 | 入力欄の文字が上下中央にそろっている（日付・選択欄を含む）。空でも入力後でも高さが変わらない |
| C4 | 文字と背景の色の差が十分で読める（ダークでも） |
| C5 | 押せる部分の高さが 44px 以上ある |
| C6 | 下の固定ボタン帯に、最後の明細やトーストが隠れない |
| C7 | 長い名前（旅行名60文字・メモ80文字・呼び名20文字）でも崩れない |
